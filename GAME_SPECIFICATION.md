# Game Design & Content Specification: Planetary Scale RTS

**Companion Document to:** [`SPECIFICATION.md`](SPECIFICATION.md) (Engine Technical Specification)  
**Target Engine:** Deterministic Fixed-Point Simulation Core (`sim-engine`)

---

## 1. Executive Vision & Core Pillars

### 1.1 The Vision
A grand-scale, flow-economy real-time strategy game inspired by *Supreme Commander: Forged Alliance*. Players command planetary armies ranging from light scouts to colossal multi-screen Experimentals, orchestrating warfare across land, sea, subsurface, air, and orbit on maps spanning up to 81×81 km (6,500+ sq km).

### 1.2 Core Pillars
1. **The Strategic Zoom:** No artificial camera boundaries. The perspective pans and zooms continuously from close-ups just above the ground out to an orbital military theater where units collapse into standardized NATO icons.
2. **The Flow-Based Economy:** An economy governed by continuous streaming rates rather than static stockpiles. Players balance resource inflow versus drain in real-time differential equations.
3. **True Physical Ballistics:** Every bullet, laser bolt, missile, and artillery shell exists as a simulated 3D physical object governed by mass, velocity, gravity, and terrain collision.
4. **Radical Faction Asymmetry:** Four factions built around fundamentally distinct tactical doctrines (heavy kinetic brute force, stealth and ambush cybernetics, extreme doctrinal zealotry and hovering, and durable alien power with death mechanics).
5. **Mass-Scale Wreckage Recycling:** War is funded by the graveyard of past battles. Debris is physical, harvestable, and strategically contested.

## 2. The Command Units (ACU & Support Commanders)

### 2.1 The Armored Command Unit (ACU)
The player’s physical avatar on the battlefield. The ACU is a multi-story walking brawler, primary engineer, and high-yield resource generator.

* **Assassination Condition:** Under standard match rules, when an ACU’s health reaches 0, its quantum reactor collapses into a massive nuclear explosion (dealing ~15,000 damage in a 25-meter radius), vaporizing surrounding bases and instantly eliminating the player from the match.
* **Overcharge Cannon:**
  * Consumes a substantial pulse of stored Energy (e.g., 3,000–5,000 Energy per shot).
  * Fires a devastating plasma burst that instantly vaporizes virtually any Tier 1, 2, or 3 mobile unit.
  * Ineffective against Tier 4 Experimentals and structures (deals scaled cap damage).
* **Modular Field Enhancements:**
  The ACU features three physical upgrade slots:
  * **Right Arm:** Heavy offensive upgrades (focused beam lasers, extended range, rapid-fire cannons, or microwave weapons).
  * **Left Arm:** Construction upgrades (expanded Build Power, automated nanite repair drones, engineering suites).
  * **Back / Sub-Systems:** Strategic utility (heavy personal bubble shields, optical cloaking / radar stealth, quantum teleportation drives, or high-yield resource generators).
* **Quantum Teleportation:**
  * Upgraded ACUs and sACUs can instantly teleport anywhere on the map within sensor coverage.
  * *Mechanics:* Requires charging an immense pre-requisite buffer of stored Energy. If energy stalls during the charge cycle, the teleport sequence aborts. Landing on enemy units triggers a "telefrag" that destroys the occupied chassis.
* **Self-Destruct (Ctrl+K):** Initiates a 5-second countdown timer leading to intentional reactor detonation. Used strategically to deny enemy reclaim, trigger tactical suicide nukes, or free up unit capacity.

**Status:** Field enhancements in all three slots, quantum teleportation, and self-destruct are built (§18.4, Field Enhancements).

### 2.2 Support Commanders (sACUs)
Constructed in the late game via the **Quantum Gateway (Tier 3)**:
* Function as autonomous sub-commanders with high baseline Build Power and heavy armor.
* Do not end the game upon death (no game-ending reactor detonation).
* Fully modular with their own faction-specific upgrade trees (combat presets, stealth suites, shield generators, or specialized engineering hives).

**Status:** Built (§18.4, Support Commanders), with one support commander for both mirrored factions. Ready-made presets from the gateway, and the engineering drone, which needs aircraft, are not.

## 3. The Streaming Economy

The game operates on a continuous rate-of-flow system measured in **Resource / Second**.

```
Net Mass Rate   = Total Mass Inflow - Total Mass Outflow
Net Energy Rate = Total Energy Inflow - Total Energy Outflow
```

```
┌─────────────────────────────────────────────────────────────┐
│                      RESOURCE PIPELINE                      │
│                                                             │
│   INFLOW SOURCES                    DRAIN CONSUMERS         │
│   • Mass Extractors (Mexes)         • Factories / Upgrades  │
│   • Power Generators (PGens)        • Engineers (Assisting) │
│   • Hydrocarbon Vents               • Shield Dome Upkeep    │
│   • Mass Fabricators (Energy->Mass) • Radar / Omni Upkeep   │
│   • Battlefield Reclaim             • Weapons (Artillery)   │
│                                                             │
│             ▲                               ▲               │
│             │                               │               │
│             └───────► [ STORAGE POOL ] ─────┘               │
│                       (Buffer Overflow)                     │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 Resource Types
1. **Mass:** The structural matter used to construct physical chassis, weapons, and buildings. Gathered from fixed Mass deposits, battlefield reclaim, or energy conversion.
2. **Energy:** The operational fuel used to power shields, sensors, weapons, construction nanite streams, and mass fabricators. Gathered from Power Generators and Hydrocarbon Plants.

### 3.2 Storage Buffers & Stalling Penalties
Small baseline storage pools buffer transient rate spikes. When storage hits zero and consumption exceeds production, the empire **stalls**:

* **Mass Stall:** When Mass hits 0, all active construction, factory queues, and upgrades slow down proportionally to match incoming revenue:
  $$\text{Progress Rate} = \frac{\text{Total Inflow}}{\text{Total Demand}}$$
* **Energy Stall:** When Energy hits 0, the consequences are immediate and catastrophic:
  * Factory and engineering build rates slow to a near halt.
  * Radar, Sonar, and Omni sensors go blind (blinking off).
  * Active energy shield domes rapidly bleed power and **completely collapse**, leaving bases defenseless.
* **Production Pausing:** Individual factories, shields, mass fabricators, and construction projects can be manually paused (hotkey toggle) to instantly cut their drain from the network without canceling queued progress.

### 3.3 Mass Fabrication (The Post-Scarcity Transition)
* **Tier 1 & Tier 3 Mass Fabricators:** Stationary structures that continuously convert excess Energy into raw Mass.
* Highly volatile: Explode violently if destroyed while active.
* Allows economies to scale infinitely beyond the physical mass points on the map.

**Status:** Built (§18.4, Mass Fabrication and Hydrocarbon Power), as the original's T2 and T3 fabricators.

### 3.4 Hydrocarbon Plants
Placed on specialized map vents. Provide high early-game energy output (equivalent to ~10–12 T1 power generators) at a fraction of the build cost, creating high-value early-game territorial objectives.

**Status:** Built (§18.4, Mass Fabrication and Hydrocarbon Power), with the original's output of 5 generators' worth.

## 4. Base Geometry & Adjacency Networks

Structures built directly touching one another share physical power and resource connections, providing passive efficiency bonuses.

```
   [PGen]                  [Storage]
     │                         │
[Factory] ◄── Energy Discount [Mex] ◄── +12.5% Mass Boost
     │                         │
   [PGen]                  [Storage]
```

* **Factory + Power Generators:** Reduces the continuous Energy cost of unit production by up to 25%.
* **Factory + Mass Storage / Mass Fabricator:** Reduces the Mass cost of unit construction by up to 15%.
* **Mass Extractor + Mass Storage:** Surrounding a Mass Extractor with Mass Storage buildings on all four cardinal edges increases extractor output by **+50%** (+12.5% per storage unit).
* **Power Generator + Energy Shields / Radar:** Reduces the continuous operational Energy upkeep by up to 25%.
* **Power Generator + Heavy Artillery:** Reduces Energy drain per shot and **decreases reload times**, directly increasing the artillery's rate of fire.
* **Volatility Hazard:** Higher-tier generators (T3 PGens) and mass fabricators contain unstable plasma cores. If destroyed, they explode with devastating kinetic force, triggering chain reactions that can vaporize adjacent base structures.

**Status:** Built with Forged Alliance Forever's adjacency table in place of the numbers above (§18.4, Adjacency), so that extractors, not storage, cut a factory's mass cost. Generators beside artillery installations also cut what each shot costs and the time between shots (§18.4, Artillery).

## 5. Engineering Dynamics & Production Scaling

### 5.1 Build Power (BP) & The Assisting Mechanic
Every constructor (ACU, Engineer, Factory, Support Commander) has a distinct **Build Power** attribute.
* **Factory Assisting:** Instead of building 20 separate factories, players can command 40 engineers to "Assist" a single factory.
* The factory's production queue drains the economy at the pooled speed of all 41 units combined, printing high-tier units or Experimentals in seconds.
* **Upgrade Vulnerability:** Upgrading a factory or Mass Extractor to the next tech tier temporarily halts its unit production or resource generation until the upgrade finishes.

### 5.2 Factory Automation & Infinite Loops
* **Repeat Mode:** Factories can toggle infinite build queue looping (e.g., repeating a strike group of 5 tanks, 2 flak, and 1 mobile missile).
* **Dynamic Rally Orders:** Rally points can be anchored to friendly units (auto-guard), transport aircraft (auto-ferry), or other factories (auto-assist upon completion).

### 5.3 The Capture Mechanic (Nanite Subversion)
* Engineers, ACUs, and sACUs can fire capture beams onto enemy structures or mobile units.
* If completed without the engineer dying or the target being destroyed, ownership of the asset permanently transfers to the capturing player.
* Allows capturing enemy technology to unlock opposing faction tech trees (e.g., UEF building Cybran stealth shields).

**Status:** Built (§18.4, Capture). Unlocking another faction's tech waits for factions (§14).

## 6. The Wreckage Economy & Denial Tactics

### 6.1 Battlefield Reclamation
Destroyed units, downed aircraft, shattered base buildings, rocks, and trees leave physical 3D wreckage on the terrain.
* **Mass Recovery:** Wreckage retains **80–84% of its remaining health value in Mass**.
* **Graveyard Flipping:** After a major mid-map clash, the victor can move mobile engineers or ACUs into the graveyard to vacuum up thousands of Mass units in moments, immediately funding higher-tier tech or Experimentals.
* **Environmental Reclaim:** Trees provide fast early Energy (and minor Mass); rocks provide pure, dense early Mass.

### 6.2 Wreckage Blasting (Denial of Reclaim)
* Wreckage possesses its own collision box and hit-point pool.
* Players can command tanks or artillery to **Force-Fire (Ground Attack)** on wreckage graveyards.
* Explosive damage vaporizes the wreckage, permanently deleting the mass from the map to prevent the enemy from reclaiming it.

**Status:** Built (§18.4, Wreck Blasting). Debris is hit where shells come down and where blasts reach, not along a shell's path.

## 7. Physics, Ballistics & Weapon Trajectories

### 7.1 Ballistic Simulation
* **True Trajectory:** Shells, plasma charges, missiles, and rockets travel with real muzzle velocity and gravitational drop.
* **Elevation & Masking:** Cliffs, hills, and base walls physically block low-trajectory fire. Artillery placed on ridges gains increased line-of-sight and clearance.
* **Physical Dodging:** Agile units (light assault bots, interceptors) can change heading to evade incoming slow-moving artillery shells or unguided rockets.
* **Friendly Fire:** Stray rounds, premature detonations, and artillery spread inflict full damage on friendly units and shields.
* **Beam Weapons:** Continuous raycast energy vectors (e.g., CzAR death rays or microwave lasers) apply damage instantly along line-of-sight without projectile flight delays.

## 8. Multi-Layered Defense Networks

Static defenses must be deployed in coordinated layers to resist high-tier assaults:

| Defense System | Ordnance Targeted | Core Mechanics |
| :--- | :--- | :--- |
| **Point Defense (PD)** | Direct ground fire | High DPS direct-fire turrets (Gauss, pulse lasers). Blocked by terrain. |
| **Anti-Air (AA)** | Aircraft (Interceptors, Gunships, Bombers) | **Flak:** High AoE burst against light clusters.<br>**SAMs:** High-damage tracking missiles targeting heavy air. |
| **Energy Shields** | All ballistic & explosive shells | Projects a 3D hemispherical dome with its own HP pool. Absorbs incoming fire until depleted. Overlapping shields suffer AoE splash bleed-through. |
| **Tactical Missiles & TMD** | Ground installations, shields | **Missiles:** High-burst cruise missiles designed to collapse shields.<br>**TMD:** Precision lasers/counter-missiles shooting down incoming warheads in flight. |
| **Strategic Nukes & SMD** | Map-wide base obliteration | **ICBM:** Enormous nuclear warhead wiping out entire bases.<br>**SMD:** Anti-nuke silos that must manually build and store interceptor missiles. |

### 8.1 Shield Mechanics & Stacking Rules
* **Directional Shield Permeability:** Friendly units inside a shield bubble can freely fire outward. Hostile projectiles coming from outside are blocked by the dome.
* **Shield Overlap Hazard:** Overlapping multiple shield generators does not create invulnerability. Explosive area-of-effect (AoE) shells that strike the outer shield will bleed splash damage into all overlapping inner shield generators simultaneously.

**Status:** Shields, tactical missiles, nuclear missiles, and both missile defenses are built (§18.4, Shields and Missiles). Point defense was already in the slice. Anti-air is built (§18.4, Aircraft, and T2 and T3 Aircraft): the T1 turret and mobile anti-air, T2 flak, which bursts among aircraft, and the T3 SAM launcher.

## 9. Information Warfare (Sensors & Intel)

Combat occurs far beyond visible optical range. Controlling the intel war dictates weapon accuracy and target acquisition.

```
┌─────────────────────────────────────────────────────────────┐
│                     THE INTEL SPECTRUM                      │
│                                                             │
│  [ OPTICAL LOS ]  Reveals unit models & direct sight lines  │
│         ▲                                                   │
│  [ RADAR / SONAR ] Identifies targets as generic blips      │
│         ▲                                                   │
│  [ RADAR STEALTH ] Masks unit blips from radar/sonar        │
│         ▲                                                   │
│  [ OPTICAL CLOAK ] Complete visual & radar invisibility     │
│         ▲                                                   │
│  [ OMNI SENSORS ] Pierces Stealth, Cloak, and Jamming       │
└─────────────────────────────────────────────────────────────┘
```

* **Line of Sight (LOS):** Direct optical vision. Only units within direct LOS reveal their 3D models and exact health bars.
* **Radar & Sonar:** Identifies surface/air and subsurface targets as generic triangular blips through the Fog of War.
* **Radar Stealth:** Eliminates a unit's radar signature (it produces no blip), but remains visible to optical eyesight or direct scouts.
* **Optical Cloaking:** Completely conceals the unit visually and electronically. Requires proximity or Omni detection to reveal.
* **Radar Jamming:** Deploys dozens of false decoy blips on enemy radar screens to mask true troop numbers and trigger false artillery bombardment.
* **Omni Sensors:** Integrated natively into all ACUs/sACUs and built as Tier 3 Omni Sensor towers. Strips away Stealth, Cloaking, and Jamming within its spherical detection radius.
* **Advanced Orbital & Quantum Optics:**
  * **UEF Novax Center (T3):** Deploys an un-targetable orbital satellite providing high-altitude persistent vision and precision orbital laser fire.
  * **Aeon Eye of Rhianne (T3 Optics Facility):** Drains continuous high Energy to project a movable remote optical sensor probe anywhere on the map through Fog of War.


**Status:** Radar, radar stealth, jamming, omni sensors, and optical cloaking are built (§18.4, Intel). Sonar waits for naval units (§10), and the orbital and quantum optics for T3 factions (§14).

## 10. Multi-Domain Warfare (Air, Sea & Subsurface)

* **Aviation Logistics & Fuel:** Aircraft utilize fuel reserves during continuous flight. Exhausted fuel causes aircraft to lose altitude and crawl at minimum speed. Players build **Air Staging Facilities** where aircraft land to rapidly refuel, rearm, and repair.
* **Subsurface Warfare:** Submarines and underwater structures are immune to surface artillery, plasma cannons, and direct lasers. Combating them requires dedicated Sonar networks, Torpedo Bombers, Sub-hunters, and Naval Depth Charges.
* **Amphibious Dynamics:**
  * **Seabed Walkers:** Heavy tanks and assault mechs walk along the ocean floor, immune to surface fire but vulnerable to torpedoes and depth charges.
  * **Hovercraft:** Skim seamlessly across water and land, bypassing naval choke points to flank shorelines.

**Status:** Flight, fuel, the Air Staging Facility, aircraft patrols, the air factories of all three tiers with FAF's UEF aircraft, and anti-air of all three tiers are built (§18.4, Aircraft, Fuel and Air Staging, and T2 and T3 Aircraft). Rearming waits for aircraft with ammunition. The torpedo bomber waits for naval units, and the transport for transporting. Surface ships are built (§18.4, Ships): naval factories of all three tiers, with support factories, and the frigate, destroyer, cruiser, battleship, and battlecruiser. So are submarines, sonar, and torpedoes (§18.4, Under the Sea). So are the shield boat, anti-torpedo charges, the strategic missile submarine, and the mobile missile launcher (§18.4, Shields That Move and Missiles From Units). Hovercraft and seabed walkers are built (§18.4, Amphibious).

## 11. The Veterancy System

Units are not static; as they destroy hostile forces, they accumulate experience equal to the Mass value of their targets, progressing through **5 Veterancy Ranks**:

```
[Rank 0: Recruit] ──► [Rank 1] ──► [Rank 2] ──► [Rank 3] ──► [Rank 4] ──► [Rank 5: Elite]
```

* **XP Thresholds:** Each rank requires destroying an amount of enemy mass equal to a multiplier of the unit's own mass cost (typically 1×, 2×, 3×, 4×, 5×).
* **Veterancy Rewards:**
  * **Max Health Increase:** Each rank boosts maximum hit points (up to +100% total HP at Rank 5).
  * **Instant Partial Healing:** Reaching a new rank triggers an immediate percentage health restoration.
  * **Passive Health Regeneration:** Unlocks permanent health regeneration per second, scaling higher with each rank.
* **Commander & Experimental Dominance:** A Rank 5 ACU, Support Commander, or Experimental unit regenerates hundreds of HP per second, turning surviving veteran units into nearly unkillable juggernauts.

## 12. Exotic Weaponry, EMP & Status Effects

* **EMP & Stun Weapons:** Cybran EMP missiles, specialized artillery, and Aeon Chrono Dampeners do not deal lethal damage. Instead, they discharge electromagnetic pulses that freeze unit firing mechanisms, disable radar, and shut down shield domes for fixed durations.
* **Gravity Tractor Claws:** The Aeon Galactic Colossus uses localized gravity beams to pick up enemy tanks, hold them immobilized in mid-air, and crush them in its internal maw.
* **Persistent Death Storms:** Upon destruction, the Seraphim Ythotha's containment core collapses into an autonomous **Dark Energy Storm** that roams the battlefield for 60 seconds, shocking and vaporizing any units in its path.

**Status:** Stuns, tractor beams, and death storms are built as mechanics any unit's data can use (§18.4, Exotic Weaponry). The units that carry them, the EMP missiles and artillery, the Chrono Dampener, the Galactic Colossus, and the Ythotha, wait for factions and experimentals (§13–§14).

## 13. Unit Formations, Movement & Macro Automation

### 13.1 Cohesive Formations
* When a diverse fleet (slow artillery + medium tanks + fast scouts) is given a formation move command, the engine **locks the entire army's speed to the slowest unit**.
* Prevents fast scouts from sprinting ahead and dying piecemeal before heavy fire support arrives.
* Giving a non-formation move order breaks the lock, letting fast units sprint at maximum speed.

**Status:** Built (§18.4). A formation move keeps the group's shape all the way to its destination, at the slowest unit's pace. A plain group move ends in the same orderly grid, but each unit travels to it on its own, at its own speed.

### 13.2 Automated Patrol Loops
Issuing a `Patrol` order across waypoints turns units into automated patrol guardians. Each unit's loop starts where it stands, so it keeps coming back there, or, given with Shift, where its queued orders end: it carries those out first, then patrols from there. A patrol given with Shift to a unit already patrolling replaces the old one, which would otherwise never end.
* **Combat Units:** Patrol the route, automatically engage enemies within sensory range, pursue within a leash radius, and return to the patrol loop.
* **Engineers:** Automatically repair damaged friendly buildings, assist active construction, and vacuum up wreckage debris within their patrol radius.
* **Aircraft:** Patrol air lanes, dogfight hostile air, and automatically divert to the nearest Air Staging Facility when fuel drops below 20%, returning to patrol once refueled.

### 13.3 Advanced Logistics
* **Coordinated Attacks (Time-on-Target):** Orders multiple strike groups from across the map to arrive and strike a target at the exact same synchronized second.
* **Automated Ferry Routes:** Air transports can be assigned continuous ferry loops. Newly constructed ground units walk to the pickup beacon, board transports, fly to the drop zone, and march to the front autonomously.
* **Custom Geometric Build Templates:** Players can save exact base layouts (e.g., optimized factory-pgen-storage rings) and place the blueprint with a single click.

## 14. Faction Asymmetry & Iconic Rosters

### 14.1 United Earth Federation (UEF)
* **Design Philosophy:** Industrial, conventional military doctrine. Heavy armor, kinetic Gauss cannons, layered static defense, and heavy frontline attrition.
* **Unique Mechanics:** Resilient mobile shield generators, defensive fortress structures, and naval cruisers equipped with long-range cruise missiles for coastal bombardment.
* **Iconic Experimentals:**
  * **Fatboy (T4 Mobile Factory):** A massive tracked, amphibious fortress with four dual Gauss turrets that manufactures land units on the move and docks repair aircraft.
  * **Mavor (T4 Strategic Artillery):** A colossal fixed artillery piece that fires shells across the entire map with zero shot dispersion (pinpoint accuracy).
  * **Atlantis (T4 Submersible Aircraft Carrier):** A nuclear submarine carrying up to 150 aircraft, shielded from surface detection and naval bombardments while underwater.

### 14.2 Cybran Nation
* **Design Philosophy:** Asymmetric warfare, ambush tactics, cybernetics, radar stealth, lasers, and multi-functional adaptability.
* **Unique Mechanics:**
  * **In-Place Shield Upgrades:** Cybran base shields upgrade sequentially in place through five tiers (ED1 to ED5) instead of requiring new footprints.
  * **Amphibious Walkers:** The *Salem-class* T2 Naval Destroyer sprouts mechanical legs and walks out of the ocean to assault land targets directly.
  * **Engineering Hives:** Static stations deploying multiple automated repair/assist nanite pods.
* **Iconic Experimentals:**
  * **Monkeylord (T4 Spiderbot):** A fast, low-cost walking spider-bot equipped with an internal **Radar Stealth Field** and a focused microwave laser.
  * **Megalith (T4 Heavy Assault Crab):** A colossal amphibious walker armed with dual proton cannons, torpedo launchers, and the ability to fabricate T2/T3 combat units on the field.
  * **Scathis (T4 Mobile Artillery Platform):** An experimental tracked vehicle capable of rapid-fire sustained artillery bombardment.

### 14.3 Aeon Illuminate
* **Design Philosophy:** Religious zealotry, single-purpose unit specialization, weapon precision, and high mobility.
* **Unique Mechanics:**
  * **Extensive Hover Capabilities:** A large portion of their light and support ground forces (light tanks, hover tanks, mobile flak, mobile TMD, and mobile artillery) glide smoothly across water.
  * *Critical Doctrinal Limitation:* Aeon's primary mainline combat brawlers—the **T2 Obsidian Heavy Tank**, **T3 Harbinger Mark IV Heavy Assault Bot**, and **T3 Sprite Striker Sniper Bot**—are tracked or walking units and **cannot hover**.
* **Iconic Experimentals:**
  * **Galactic Colossus (T4 Assault Bot):** A towering, heavily armored monolith armed with optic lasers and gravity tractor beams that vacuum up enemy tanks and crush them.
  * **CzAR (T4 Flying Fortress):** A colossal hovering saucer that acts as an aerial carrier and fires a continuous underside death ray that incinerates everything beneath it.
  * **Paragon (T4 Resource Generator):** Once completed, provides practically infinite Mass and Energy by matching any expenditure rate. Possesses extremely fragile housing and detonates with catastrophic force if destroyed.

### 14.4 The Seraphim
* **Design Philosophy:** Advanced alien invaders featuring high unit costs, massive health pools, advanced energy shields, and battlefield regeneration.
* **Unique Mechanics:** Units feature the highest raw HP and damage per tier, backed by the strongest static energy shields and regenerative auras on their ACU/sACUs. Units like the *Selen* T1 Scout possess passive cloak and radar stealth when stationary.
* **Iconic Experimentals:**
  * **Ythotha (T4 Assault Bot):** A massive bipedal walker armed with heavy energy weapons and an EMP lightning arc. Upon destruction, its unstable reactor spawns a **Dark Energy Storm**—an autonomous, destructive ball of energy that roams the battlefield damaging nearby units.
  * **Ahwassa (T4 Strategic Bomber):** A massive experimental flying wing that drops an orbital-class sub-atomic bomb capable of flattening a T3 base cluster in a single run.
  * **Yolona Oss (T4 Strategic Missile Launcher):** Fires a specialized **Super-Nuke**. Unlike standard nuclear missiles, the Yolona Oss warhead possesses hardened shielding that **requires two (2) separate Strategic Missile Defense (SMD) interceptors** to shoot down, rapidly overwhelming conventional anti-nuke grids.

## 16. Game Modes & Victory Conditions

1. **Assassination (Standard Competitive Mode):** The match ends when a player’s ACU is destroyed. All structures and units belonging to that player immediately self-destruct or go neutral.
2. **Annihilation:** The match ends only when all enemy mobile units, factories, and combat structures are completely eliminated. Losing an ACU does not end the match.
3. **Supremacy:** A player is eliminated if they lose both their ACU and all Support Commanders or all factories.
4. **Shared Armies & Reclaim Permissions:** Teammates can dynamically transfer units, economic income percentages, or full army control to allies.

## 17. Opponents & Multiplayer

* **First Playable:** One human against a scripted AI. The AI issues commands through the same `SimCommand` interface as a player and sees only what its team's intel allows.
* **Difficulty:** The player's opponent is Easy unless they ask for Normal (`--ai normal`, or `?ai=normal` in the browser). Easy keeps a small economy and army, at most 3 engineers, 2 land factories, 16 land combat units, 4 aircraft, 3 ships, and 1 point defense, decides every 3 seconds instead of every second, and plans as if it had half its income, so it climbs the tech tree late. It defends from the start but attacks only after 12 minutes, in waves of 6 growing to 12, and never fires missiles or overcharge or sends its commander. Planning on half its income alone made it stronger, not weaker: it stopped spending on its economy and tech and put everything into early units, and beat Normal in all six test matches. With the caps, Normal fields at least half as many units again by 20 minutes. AI-vs-AI matches, and so the soak, always play Normal.
* **Automated Matches:** AI-vs-AI matches run headlessly, serving as full-match regression tests and as the first tool for balance tuning.
* **Multiplayer (Later):** Lockstep over the network, exchanging only commands and comparing checksums to detect desyncs. Matchmaking, lobbies, and transports are not yet specified.

Built since the slice: wreck blasting (§6.2), shields and missiles (§8), intel (§9), formations (§13.1), veterancy (§11), tech tiers up to T3 structures, the commander's enhancements, teleport, and self-destruct (§2.1), support commanders (§2.2), mass fabrication and hydrocarbon plants (§3.3–3.4), and capture (§5.3).

### 18.3 Exit Criteria
* A human can win or lose a full match against the AI.
* 100 headless AI-vs-AI matches finish without a crash or checksum mismatch when replayed. Check with `cargo run --release -- --soak 100`.
* The engine's tick and frame-rate gates still pass during a late-game match. Check the frame rate with `cargo run --release -- --autotest 60 --fast-forward 10000`.

### 18.4 Implementation Decisions
These are starting points for tuning, recorded because they interpret or adjust the design above.

* **Scale:** One terrain cell (20 units) is the game's basic grid square. Unit sizes, speeds, and ranges in `data/units.toml` are set in proportion to it, and the skirmish map is 10 km across.
* **Mirror Fairness:** On a mirrored map, a unit and its mirror image heading the opposite way move exactly alike: a direction is scaled by a speed, a distance, or an angle's cosine with rounding toward zero, where the fixed-point type's own product rounds toward negative infinity. Before this, the side heading toward lower coordinates moved a 4,096th of a unit further on every step. It wore away the mirror within a few minutes, always the same way, and the AI-vs-AI soak went 255 to 193 for Blue; afterwards 127 to 120. Mirrored fights are still decided by tie-breaks such as which unit's staggered target search comes first, which follow unit ids, not sides.
* **Commander Explosion:** §2.1 gives a 25-meter radius, which is barely more than one grid square and could not "vaporize surrounding bases". The slice uses 300 units, as a data value.
* **Friendly Fire:** A shell ignores allies until it reaches its aim point, so that rear ranks can fire through front ranks. Rounds that overshoot can hit allies, and splash damages everyone, which keeps the stray rounds and artillery spread of §7.1.
* **Fog of War:** Sight is a simple radius, not blocked by terrain. Units cannot target what their team cannot see. Structures are not remembered once out of sight.
* **Upkeep:** Shields are the only upkeep so far, and are paid before building, so that building takes what is left. A team that cannot pay for a dome loses it (see Shields). Sensor effects from §3.2 arrive with sensors.
* **Orders During Construction:** A factory takes queue, repeat, rally, and upgrade orders while it is under construction. They wait at no cost, and production starts once it is built.
* **Work Beams:** A builder faces what it is working on, joined to it by an animated beam, which covers building, assisting, repairing, and reclaiming. A team with nothing to spend shows no beams, so a beam always means progress. This is presentation only, and not part of the checksum.
* **Control Groups:** Ctrl or Command plus a number saves the selection, and with nothing selected clears that group. The number alone selects it. A bar on the left lists the groups in use and what is in them, and clicking one selects it. Dead units drop out.
* **Turning:** Each mobile unit has a turn rate, in degrees per second, and may have a turn radius, in units. A unit only moves forward along its facing. With a turn radius it turns like a car: only while moving, in an arc no tighter than its radius, slowing to half speed in a tight turn but never stopping, so a U-turn swings out to the side. A goal inside the circle it would turn in cannot be reached by driving on, so it pivots slowly on the spot instead, as a tracked vehicle would. Without a turn radius it turns on the spot, as a walker does. The commander's legs and the engineer's hull follow the facing, while the body and arm above turn freely to face their work. Values: commander 180 degrees a second on the spot, engineer 240 with a 10-unit radius, light bot 360 on the spot, light artillery 120 with 30, heavy tank 90 with 40. Stress test units turn instantly. Planned: naval units turn slowly, and air units cannot stop or turn on the spot, so they must fly in arcs and circle; their turn rate matters most.
* **Turrets:** Each weapon has a turn rate, in degrees per second, and swivels towards its target by at most that much each tick. It only fires when it points within about 6 degrees of the target. Without a target it turns back over the hull. The commander's gun arm, the bot's upper body, the tank's turret, the artillery's barrel, and the point defense's gun are drawn from it. Rates: commander 180, light bot 300, light artillery 90, heavy tank 60, point defense 120. Stress test units fire in any direction at once.
* **Unit Paint:** Each part of a unit's shape is painted one of four ways: team color, armor, dark gunmetal, or a glow. Armor is grey, taking on a little of the unit's own tint, which shows what it is, and a little of the team color. Gunmetal is the same for everyone, for guns, tracks, legs, and masts. Glowing parts, such as engines, emitters, and the commander's visor, take the unit's tint at full brightness and are never shaded, and a structure's parts glow only once it is finished. Every unit shows its team color somewhere that can be seen from above. Colors are chosen as they look on screen and lit in linear light, with light from the sky above, the ground below, and the sun, a soft shine, and a faint light along edges so that outlines show against the ground. A unit shrunk to a tactical dot is all team color.
* **Unit Models:** Every unit and structure is an original low-poly model, built in code from blocks, beveled blocks, prisms, drums, and arches, and shaped so that what it is can be read from above. Ships are long and narrow, about four times as long as they are wide, with a dark band at the waterline and a raised deck at the bow, and each class has its own layout: the frigate's single gun and landing pad, the destroyer's guns fore and aft and torpedo tubes, the cruiser's missile cells and radar mast, the battleship's three twin turrets clear of a stepped tower lined with small guns, the battlecruiser's raked tower, rounded submarines with a tower amidships, glowing hatches on the missile submarine, and the shield boat's emitter mast. Factories, generators, and extractors look different at each tier, with more halls, stacks, gantries, towers, and lights as they go up. Aircraft have bodies that taper to a point, wings thick at the root and thin at the tips, small slanted canopies, and glowing engine nozzles; the strategic bomber is a flying wing with a raised middle and engines on top. Gunships have streamlined bodies with a tail boom and four slim rotor blades, the heavy gunship two rotors, and bots carry a gun in one arm. The commander has a team-colored chest with a glowing core, a backpack with glowing vents, shoulder pads, a gun on its right arm, and a helmet with a glowing visor, on jointed legs with feet. Engineers have tracks and a jointed arm on a team-colored turntable, tanks have fenders, engine grilles, and turrets with mantlets and muzzle brakes, artillery braces on spades, and turrets stand on stepped plinths with a team-colored ring. Support factories look like the tier they build.
* **Unit Animation:** Units move as well as travel. Walkers' legs swing through strides as far as they walk, and come back straight when they stop. Rotors and radar dishes turn. Guns kick back with a muzzle flash as they fire, for a moment after each shot. Structures being built stand in scaffolding as tall as they will be, until they are finished, and factories' and builders' lights shine while they work and dim while idle. All of it follows the game's own clock, so that it stops while the game is paused, and none of it is ever read by the simulation.
* **Effects:** Shells burst into a small fireball where they land, and units explode as they die, with a fireball and smoke that rises and drifts away, larger for larger units. Smoke is see-through, thinner at its edges and as it ages, and no two puffs are quite alike in shape, size, or shade. Missiles leave a trail of smoke that spreads and fades behind them, and their blasts are bigger, a strategic missile's far bigger. Ships on the surface leave foam behind them that spreads and fades on the water. What lands on the ground leaves a crater, a dark bowl ringed with thrown-up earth, and units that die on the ground scorch it black, so that a battlefield shows where the fighting was. The marks are only drawn: the ground's shape never changes, so they make no difference to play. They fade away over a few minutes, and nothing is marked under water. Effects are drawn from what the player can see and never touch the game, and they stop while it is paused.
* **Terrain and Water:** Ground is grass, darker in the lows and drier on the heights, in soft patches with bare dirt here and there, rock where it is steep, in layers of lighter and darker stone with cracks between, and sand along the shore, with faint contour lines on gentle ground for scale. Hills are lit smoothly, and hollows, gullies, and the feet of slopes are darker while crests catch a little more light, so that the shape of the land reads from far away. Up close, small bumps break up the light, and the grass is speckled with lighter and darker blades and small stones, all of which fade away as the camera rises so that nothing shimmers at a distance. Water is a see-through surface: clear and pale in the shallows, dark and deep blue further out, with the ground below darkening with depth, the sky showing in it at a glancing angle, a gentle drifting shimmer, and foam where it laps the shore. Ships float in it, and submarines show dimly through it.
* **Shadows:** Units, structures, aircraft, trees, and rocks cast shadows with their own outlines, away from the sun, onto the ground or the water. An aircraft's shadow is lighter the higher it flies, and overlapping shadows are no darker than one. Shadows fade with their units into tactical dots, and anything under water casts none. Edges are smoothed by drawing each pixel from several samples.
* **Shield Look:** A dome is drawn as a bubble over what it covers: almost clear where it is seen face on, with faint hexagons on its surface and a thin bright rim, so that the base inside stays easy to read. Only its near side is drawn, its hexagons fade before they are small enough to shimmer, and it fades out as the camera comes close, so that it never hides the view from inside. It grows fainter as the shield wears down.
* **Unreachable Orders:** An order that cannot be reached is cancelled as soon as a unit's up-to-date flow field shows no way from its cell to the goal. That covers walls and structures today, and impassable mountains, water for land units, and land for ships once those exist, since each is only more cells a unit cannot cross. Builders drop the task, patrols end, queued units move on, and the player is told. A goal that can be reached by a long way round is never cancelled.
* **Moving Orders:** While Shift is held, each order that can move has an icon, and dragging it puts the order somewhere else, for every unit sharing it. Moves and rally points can go anywhere. Builds follow the usual placement rules, so an extractor still snaps to a free deposit, and a build dropped where it cannot go stays where it was. A site that has started, a patrol, an attack, and a follow order cannot be moved.
* **Selection Rates:** The command panel shows what a selected structure or commander makes, including adjacency bonuses, and what a factory is really spending, including help and stalls.
* **Queued Orders:** Shift queues an order after what the selection is already doing, in any mix of moves, attack-moves, builds, assists, repairs, and reclaims. A group shares one route per queued order, and forms up at each stop. A builder finishes a walk it is on before starting what was queued, even if that job is already within reach. A queued attack is an attack-move to where the target was, and follow orders and patrols have no end to wait for: following is not queued, and queuing an order ends a patrol. A patrol can itself be queued, as the last thing a unit does, starting from where the queue ends (§13.2).
* **Quick Select Bar:** A bar on the right selects the commander or factories from anywhere, without moving the view. Factories are grouped by kind, then tier, with counts. A tier selects the factory closest to the center of the view, a double-click selects all of them, and Shift adds to the selection. Factories still being built count, as they take orders.
* **Sound:** Generated in code, and never read by the simulation. Picking units by any means gives a short tick, including picking the same units again. Builders make a light hum and factories a slightly harsher buzz, only for work in view when zoomed in, and only while work is really happening. An alarm and a text alert show when the commander takes damage, then wait 30 seconds, wherever the camera is.
* **Unit Order Bar:** Anything that can walk shows Move, Attack-move, Patrol, Assist, and Stop in the command panel. Assist means staying with a friendly unit and firing at what comes into range, without chasing it. Builders also lend their build power if the unit has work that can use it. An armed order is shown on its button, and is cancelled by right-click or Esc.
* **Command Panel Hotkeys:** Every option in the command panel shows its key in bold, which does the same as its button. A build bar opens at the highest tech level the selection can build, every time the selection changes. While a structure is being placed, a ring on the ground around where it would go shows each range it will reach, named and colored by kind: its weapons, and for artillery the range too close to hit, its shield, missile or torpedo defense, radar, sonar, omni, and stealth field. Unit orders have a key each. Build items take the key of their slot in the build bar: each kind of thing has its own slot, the same at every tech level, so that anti-air, missile launchers and defenses, fabricators, engineers, and each line of aircraft keep their key as the levels go up, and the key acts on the level the bar shows. Two kinds that are never at the same level may share a slot. Builders' bars and factories' bars use the same keys, Q E G T C Z V B H N , . / ; ' by slot, since only one bar is shown at a time: with a builder and a factory selected together, the factory's bar is shown and takes the keys. The key above Tab shows the next level in the bars. N mutes, and - and = set the volume, when they do nothing else. Keys are mostly on the left of the keyboard, because the other hand is on the mouse.
* **Queuing Ahead of an Upgrade:** Once a factory has an upgrade queued, it also takes what the upgrade unlocks. New items go to the end of the queue, so they can only come out after the upgrade has finished. Removing the upgrade removes what depended on it.
* **Removing Queued Orders:** The command panel lists the selection's queue, and right-clicking an item removes it. Orders are named rather than numbered, because a queue can move on between the click and the command arriving. A site that was already started stays where it is, without a refund, and can be finished by assisting it. A factory loses its last matching item, so that work under way is only lost if it is the only one.
* **Arrival Formations:** A group ordered to a location forms a grid about twice as wide as it is deep, centered on the goal and lined up across the direction of travel. Units follow a shared route, then walk to their own spots, with a time limit so that a blocked spot cannot trap a unit.
* **Production Pausing:** A factory or construction site can be paused with O or the panel button, and resumed the same way. It spends nothing and makes no progress until resumed, keeps its queue and progress, and builders helping it wait beside it. Shields and mass fabricators will pause the same way when they exist.
* **Overcharge:** The commander's Overcharge spends 3,000 stored energy on one shot of 12,000 damage, which destroys any current mobile unit, but at most 800 to a structure. It has its own 5-second reload, and fires through the commander's gun arm, so it has to aim first. Ordered with L and a click on an enemy, the commander closes to range and fires as soon as it has the energy, and the order ends if the target dies. Values are in the unit data. The AI uses it (AI Defenses and Intel, below).
* **Veterancy:** The unit that destroys an enemy earns its mass as experience, or as much of it as had been built, and splash damage counts. Nothing is earned for destroying its own side. Rank n is reached at n times the unit's own mass cost, up to rank 5. Each rank adds 20% of base health, so rank 5 doubles it, heals 25% of the new maximum at once, and adds regeneration of 0.2% of maximum health a second, so a rank 5 commander heals about 120 a second. Stress test units have no mass, so they earn nothing.
* **Intel:** Each team has radar and omni coverage, stamped in turns with sight. An enemy on a team's radar or omni that it cannot see shows as a blip: a triangle that says nothing of what it is. The Radar (T1, 60 mass) covers 2,320 for 10 energy a second, and upgrades in place with U to the T2 Radar (180 mass and 3,600 energy, 78 seconds on its own build power of 10), which covers 4,000 for 150 energy a second, and that to the Omni Sensor (T3, FAF's 2,400 mass and 30,000 energy, 120 seconds on the T2 radar's build power of 20, and 100 health), which covers 12,000 with radar and 4,000 with omni for 2,000 energy a second. The Stealth Field Generator (T2, 300 mass, 25 energy a second) hides every friendly unit within 480 from enemy radar, itself included, and puts 8 decoy blips on enemy radar within 620 of it. Decoys move every 5 seconds, to spots taken from a hash of the generator and the time rather than the simulation's random numbers, since they are only ever shown. Omni strips stealth, cloaks, and decoys where it reaches, and sight shows a decoy is not there. The commander has 480 of omni built in, and with the Personal Cloak enhancement (Field Enhancements, above) a cloak, switched with O (when nothing selected can be paused) or its button, that hides it from sight and radar: an enemy cannot see or target it unless it has omni there or a unit of its own within 100. A cloak that cannot be paid for switches off. Intel upkeep is paid after shields, in `SimId` order, and a structure that cannot be paid for switches off, showing "off: no energy", until it can. Pausing switches it off without cost. Touching power generators cut upkeep by up to a quarter, as for shields. Only cloaks change what can be targeted, so radar is for seeing: to shoot at a blip, attack the ground there, which is also how decoys draw fire onto nothing. Zoomed out, the outer edge of the viewer's radar coverage, and inside it its omni, is drawn as lines: each sensor's circle, less what lies inside another's. The keys are `[` for the Radar and `]` for the Stealth Field Generator. Stealth and jamming share one structure so that both fit in the last keys. The AI builds radar and meets ground blips near its base (AI Defenses and Intel, below), so decoys can draw it; it builds no stealth.
* **Tech Tiers:** T1 engineers and the commander build T1 structures. The T2 land factory builds T2 engineers (12 build power), and upgrades in its queue to the T3 land factory (3,200 mass, 90 build power), which also builds T3 engineers (30 build power). T2 engineers add the Shield Generator and the tactical missile launcher and defense. T3 engineers add the strategic missile launcher and defense. The commander reaches T2 and T3 through its engineering suites, which are field enhancements (Field Enhancements, below): its list holds the T3 structures, and what it can build is what is on its list up to its tier, or its suite's. From the moment a suite is started, what it unlocks can be ordered: such a build is queued behind the suite whether or not Shift is held, so it never cancels the suite, and starts once the suite is done. A suite that is cancelled takes the structures queued for its tier with it. A structure's build power drives only its own upgrades, and never makes it a builder. As in FAF, T2 and T3 builders also build the higher tiers of the basic structures directly, at what the upgrade costs: the T2 and T3 mass extractors, the T2 and T3 power generators (FAF's UEF numbers: 500 and 2,500 energy a second, 3 by 3 and 5 by 5, blowing up for 1,500 within 100 and 5,500 within 200), the T2 radar and the omni sensor, and the T2 point defense (210 every 1.7 seconds within 40 of where it lands, out to 1,000: the original's three shells of 70 as one). The radar now upgrades to the T2 radar (FAF's: radar 4,000, 150 energy a second), which upgrades to the omni sensor. Factories upgraded to T2 or T3 are headquarters. T2 and T3 builders also build FAF's support factories, for far less (the T2 land one 580 mass, the T3 one 1,440; the T2 air one 510, the T3 one 1,510), but only while the team has a finished headquarters of that kind and at least that tier. A support factory builds nothing above the tier of the team's best headquarters of its kind, and upgrades from T2 to T3 only with a T3 headquarters: without one, such an item waits in its queue at no cost, and the build menu leaves it out. With factories of two tiers selected, the upgrade button is for the lowest tier, and only the factories that upgrade to the same thing take it. The AI climbs to T3 (§18.4, AI Tech and Economy).
* **Field Enhancements:** Enhancements are data, in `[[enhancement]]` tables beside the units, each with its slot, cost, build time, the enhancement it builds on, and its effects, which are totals over the unit's own blueprint, not steps. The commander's ten use Forged Alliance Forever's numbers: in the right arm, the Heavy Cannon (800 mass, 24,000 energy; the gun's range from 440 to 600 and damage from 70 to 140, the original's 30 range for 22 and double the damage); in the left arm, the T2 Engineering Suite (800 mass, 21,000 energy, 1,000 build time; 42 build power, T2 structures, 2,000 more health, healing 10 a second), the T3 Engineering Suite, which builds on it (2,400 mass, 50,000 energy, 8,400; 100 build power, T3, 3,000 more health, 20 a second), and the Nano-Repair System (800 mass, 24,000 energy; 1,500 more health, 40 a second); and on the back, the Personal Shield (2,300 mass, 112,500 energy; a dome of radius 30 with 19,000 health, 250 energy a second), the Shield Generator Field (1,400 mass, 40,000 energy; radius 200, 5,000 health, 200 a second), Personal Stealth (650 mass, 14,000 energy; off enemy radar for 50 energy a second, 2,000 more health), the Personal Cloak, which builds on it (6,000 mass, 750,000 energy; the §9 cloak for 3,000 a second while on, 12,000 more health), the Personal Teleporter (15,000 mass, 1,500,000 energy), and the Resource Allocation System (5,000 mass, 175,000 energy; 14 mass and 2,500 energy a second). Slots follow §2.1 rather than the original where they differ: the teleporter and resource allocation go on the back. A commander has one enhancement in each slot. Starting one removes what is in its slot at once, and that is lost, unless the new one builds on it, which stays until the new one is done. One that builds on another includes it: with the T3 suite, the T2 one shows as there and cannot be taken again, which would only be a step back, and the same goes for stealth under the cloak. Their effects replace each other, as the original's buffs of one type do, so the T3 suite's 3,000 health is all it adds, not 3,000 on top of 2,000. It works like an upgrade in place: the commander stands still, puts all its build power into it, engineers can assist, and a new order cancels it, losing what was spent. Health added comes with the enhancement and goes with it, and veterancy adds its share on top. Shields from enhancements are ordinary domes that move with the commander. The commander no longer has a cloak built in: §2.1 puts it on the back. **Teleport** (Ctrl+T, then a click) needs the teleporter, and a spot that is open ground in sight or on the team's radar or omni. It costs what Forged Alliance Forever's does, worked out in the original's units, a twentieth of ours: 100,000 energy plus half the distance to the power 2.1, up to 2,500,000, over 20 seconds plus a hundred-thousandth of the distance to the power 2.1, up to 50. The power is worked out in whole numbers, to 1/2048, so that every machine agrees. The energy is paid evenly every tick, after shields and intel, and the charge aborts on the first tick it cannot be paid, as §2.1 asks, where the original slows down instead. The commander stands still while charging, and a new order cancels it. It lands on the spot, and any enemy mobile unit it lands on is destroyed. A ring shows where, filling as it charges. **Self-destruct** (Ctrl+K) counts down 5 seconds for any of the player's units, and pressing it again stops the count. The unit then dies with its death explosion, the commander's reactor included, which ends the match, and it leaves no debris. The enhancements are buttons under a collapsible heading in the command panel, slot by slot, with their costs and what they do, since there are no keys left. The AI does not use them.
* **Support Commanders:** FAF's UEF numbers. The Quantum Gateway (T3, 3,000 mass, 30,000 energy, 4 by 4, 10,000 health, 120 build power) is built by T3 engineers, support commanders, and the commander with its T3 suite, and builds the Support Commander (2,100 mass, 25,200 energy, 14,400 build time, so 120 seconds at the gateway alone). It has 16,000 health, 56 build power, the T3 engineer's list and the gateway, a gun with three times the commander's fire (300 a second, range 500), 1 mass and 20 energy a second, 275 mass and 500 energy of storage, and 320 of omni. Its death sets off a small blast, 1,000 within 200, and does not end the match: only the commander's does. Mobile units' income and storage now count for any builder, not only the commander. Its enhancements follow §2.1's slots, as the commander's do, so both weapon upgrades are in the right arm and only one can be had at a time, where the original puts one in each arm: the Heavy Plasma Refractor (800 mass; range 700 and a 40 blast, the original's 35 for 25) and the Energy Accelerator (1,000 mass; twice the rate of fire); in the left arm, the Rapid Fabricator (800 mass; 98 build power, FAF's Aeon one, since the UEF one is a flying drone, which needs aircraft) and the Enhanced Sensor System (600 mass; sight 900 and omni 1,600); and on the back, the Personal Shield (26,000 health, 500 energy a second), the Shield Generator Field built on it (radius 200, 52,000 health, 1,000 a second), the Radar Jammer (300 mass; 5 decoys within 520 for 100 energy a second, as the stealth field generator's decoys work), the Personal Teleporter (FAF's Aeon one: 15,000 mass, 21,000 build time), and the Resource Allocation System (10 mass and 1,000 energy a second). The original's ready-made presets, support commanders built with enhancements on, are not built. The AI does not build gateways.
* **Mass Extractor Upgrades:** FAF's UEF numbers. The T1 extractor (36 mass, 400 health) makes 2 mass a second for 2 energy a second, and upgrades in place with U, at its own build power of 10, to T2 (900 mass and 5,400 energy for the upgrade, 90 seconds; 2,000 health, 6 mass for 9 energy), which upgrades at its 15 to T3 (4,600 mass and 31,625 energy, about 192 seconds; 7,000 health, 18 mass for 54 energy). Like factories, the higher tiers are reached only by upgrading. An upgrading extractor keeps making mass at its old rate, as in the original, and engineers can assist. Extractors pay their energy after shields, intel, and teleports, and when a team cannot pay it all, every extractor makes the same share of its mass, as an energy stall does in the original, instead of switching off in turn. The resource bar shows what they really make. A paused extractor makes and spends nothing, and generators beside one cut its upkeep as they do other structures'. The AI upgrades its extractors to T2 and T3 (§18.4, AI Tech and Economy).
* **Mirrored Paths:** A span where two sectors meet is entered at its middle cell, and a span an even number of cells long has two. It takes the one nearer the middle of the map, so that a span and its image turned 180 degrees pick cells that are images of each other, and mirrored units walk mirrored paths. It used to take the one at the higher index, which sent a mirrored engineer a few units off its partner's path.
* **One Scale:** Every range and radius is on one scale: the original's, at twenty of our units to one of its, as maps load (Maps From Files, below), where the slice had set some of its own. Sight, radar, omni, stealth and shield radii, weapon ranges and blasts, missile defense ranges, and build ranges all follow FAF's values: the commander sees 520 and has 480 of omni, the light bot sees 360 and reaches 280, the tactical missile launcher reaches 5,120, and the radar covers 2,320. Movement speeds, projectile speeds, and unit sizes keep the slice's own values for now: converting them needs gravity matched for artillery arcs, and changes how fights feel rather than how ranges compare. Minimum ranges, which the original's artillery and missile launchers have, are not built. The stealth field generator's decoys, which the original does not have, scale with its field, to 620. The commander's death blast keeps the 300 set above.
* **Capture:** As in the original: builders that can walk, engineers, the commander, and support commanders, capture an enemy unit or structure in half its build time at their combined build power, for its energy cost, which an energy stall slows like any work. Progress is kept on the target and lost if every capturer stops, so a capture that is interrupted starts over. The captured unit changes sides as it is, with its health, veterancy, and enhancements, and with nothing to do: its orders and a factory's queue, repeat, and rally point are cleared, a pause or self-destruct is dropped, and units that were shooting it stop. Its income and storage go to its new team. Commanders and support commanders cannot be captured, as in the original, nor can structures still being built. Engineers repairing a unit stop once it is captured from them. Right-clicking an enemy has selected armed units attack it and builders that cannot fight capture it; Ctrl+C arms a capture for any builder, the commander included. A capture shows as a work beam, and in the plan as a support step. The AI does not capture.
* **Mass Fabrication and Hydrocarbon Power:** FAF's UEF numbers, so the fabricators are T2 and T3 rather than §3.3's T1 and T3, and the plant makes 100 energy a second, 5 generators' worth, rather than §3.4's 10 to 12. The Mass Fabricator (T2, 200 mass, 4,000 energy, 360 health, 1 by 1) makes 1 mass a second for 100 energy a second, and the T3 one (4,000 mass, 120,000 energy, 6,000 health, 3 by 3) 16 for 1,500. Fabricators draw their energy with the extractors, so a stall slows both by the same share, and generators beside them cut it. One destroyed while running, that is finished, not paused, and with energy to run on, blows up: 370 damage within 100, or 5,000 within 200. The Hydrocarbon Power Plant (T1, 160 mass, 800 energy, 1,800 health, 3 by 3) makes 100 energy a second, and is built with a hydrocarbon vent under the middle of its footprint. Vents are part of the map, like deposits, and no other structure may cover one. Maps from files keep their vents, and both bundled maps have them: one near each base, and more out on the map to contest. The AI builds a plant on the free vent nearest home, within 2,500, when its energy runs short, before any generator; it builds no fabricators. Placing a plant marks the free vents and snaps to them, as placing an extractor does deposits, and vents are drawn on the ground.
* **Bundled Maps:** Two maps come with the game, this game's own so that they can be shipped (§20), inspired by maps the community made for the original but generated separately, from nothing of theirs: `--map highland` and `--map twin_passes`. Each is generated in the simulation from a fixed seed with whole-number math, so it is the same map on every machine and in every match, and only the match's own seed varies the play. Both turn into themselves about the map's center, as the AI's base plan does. The hills are value noise averaged with their own turned image, because copying one half onto the other leaves a seam of false cliffs down the middle row; features are then placed in pairs. Highland is 10 km: a plateau of rolling hills, steep-sided outcrops and short ridges kept clear of the bases, about 1,500 rocks in fields and 200 trees, 46 deposits, and starts in opposite corners. Twin Passes is 20 km: a sea down the middle whose west coast wanders, with the east coast its turned image, crossed by two land bridges at 32% and 68% of the way with two deposits on each, forests on both shores (about 1,600 trees), 78 deposits, and starts facing each other across the water. Cells steeper than 0.75 of height per unit of ground, or under the water, are blocked, as on maps from files. In 24 AI matches each, Highland went 15 to 9 and Twin Passes 11 to 12 with a draw, with no replay mismatches, and tick p99 2.7 ms and 5.3 ms. Tests check each map turns into itself, that the starts are joined by land, that every deposit is on open ground, and that the bridges cross. Ground under the water level is drawn as water, darker with depth, and the placement preview now knows steep and flooded cells as well as walls. `examples/map_picture.rs` draws a bundled map from above, for designing them.
* **Maps From Files:** `--map <folder>` plays a 1v1 on a map made for *Forged Alliance*, from the unzipped folder a player already has (§20: none are shipped), with `--starts a,b` choosing which two of its armies' starts Blue and Red take (1 and 2 by default). It works for every mode: playing, `--headless`, `--autotest`, and `--soak`. The importer lives outside the simulation and hands it only whole numbers, so every instance builds the same world: the map's 10 km of 512 units is our 10,240, one of its units to each of our 20-unit cells, so its heightmap maps onto our cell corners one for one. Heights are kept from the lowest point up, and a map whose hills rise more than about 100 of its units is refused, as our heights stop at 2,047. A cell whose corners differ by more than 0.75 of the original's units of height per unit of ground, about its own limit, is blocked for land units, as is ground wholly under water, until naval units (§10). Mass markers become deposits, and its trees and rocks become ours, with our reclaim values: a group of trees is one tree. Trees and rocks wholly under water are left out, since land units could never reach them. Hydrocarbon vents are kept, and other props are skipped. The loader says what it took and what it left out. A zip is refused with advice to unzip it, since the game has no zip reader. The AI takes its home and the enemy's from the map's starts instead of the skirmish's, and rallies toward the enemy along each axis, which is what it did on the skirmish map. Its base plan is Blue's, turned 180° for Red, so it plays best on maps whose two starts mirror each other. On a map with cliffs in nearly every sector, rebuilding the pathfinding graph after each structure searched every sector, and ticks reached 46 ms. Each sector now keeps the walking distances found inside it, which depend only on its own cells, until a structure goes up or comes down in it, which brought them back to 3.65 ms with identical results. On a test map, 24 AI matches finished, 11 to 11 with 2 draws, with no replay mismatches. Finding the walkable cell nearest an order's goal searched square rings outward, rescanning each whole square: on a 20 km map with a sea, a goal in the water cost thousands of cells per ring. It now visits only each ring's own cells, with the same winner, nearest and then first in row order, which took that map's average tick from 2.49 ms to 0.34 ms. Since mass extractors gained upkeep, the AI favors Blue on that test map at starts 1 and 2. That map's second start is one of its units off the mirror image of the first, though its terrain and deposits mirror; with the second start moved to the exact mirror, the matches come out even (8 to 7, 1 draw). The AI lays out its base from its start, so the offset carries into every site it picks.
* **Missiles:** A missile flies itself to a spot: up to its cruise height above the ground, along the ground at that height, which takes it over walls and hills that stop shells, and down a straight line over the last three cruise heights to just below the spot. It climbs no steeper than 45 degrees, and never hits friends on the way. As in the original, missile launchers build their missiles, keep them up to a stock limit, and fire only on order: they never pick a target themselves, and building stops, costing nothing, while a silo is full. A right-click on an enemy orders the selected launchers to fire at it, and attack ground (I) at a spot. The Tactical Missile Launcher (450 mass, tier 2) builds tactical missiles in its queue, at 140 mass and 2,000 energy, in 30 seconds at its own 10 build power, and keeps up to 6. It fires one 1,500-damage cruise missile, with a 30-unit blast, every 15 seconds while it has any, at 18 units a tick, cruising at 60, to anywhere within 5,120, and goes on firing at its target until the target is gone or it has none left. Shields stop tactical missiles, which is what they are for: four collapse a dome. The Tactical Missile Defense (200 mass) shoots down the nearest enemy cruise missile within 620 of it, instantly, then reloads for 3 seconds. A missile crosses that in about 34 ticks, so it gets two shots at a volley, and a third missile gets through. The Strategic Missile Launcher (2,000 mass, tier 3, 3 by 3) builds nuclear missiles in its queue, like a factory, at 2,000 mass and 40,000 energy each, and keeps up to 5. Each Attack or attack-ground order fires one, anywhere on the map, at 25 a tick, cruising at 500. Its blast has the original's two rings, at twenty of our units to one of its: 70,000 damage within 600, which kills anything, commanders included, and 500 more within 800, which kills light units and structures. It hits friend and foe, and clears debris. Shields do not stop it. The Strategic Missile Defense (1,000 mass, 2 by 2) builds interceptors the same way, at 500 mass and 6,000 energy, keeps up to 7, and spends one on any enemy nuclear missile that comes within 1,800 of it across the ground, wherever the missile is headed, as in Forged Alliance Forever. Defenses act before anything moves each tick, in `SimId` order, and never shoot the same missile twice. A shot-down missile simply vanishes, with a flash from the defense to it. The panel shows how many missiles or interceptors a silo holds. The AI builds tactical missiles and their defense, but no nuclear ones yet (AI Defenses and Intel, below).
* **Shields:** The Shield Generator (300 mass, 3,000 energy, 2 by 2) holds a dome of radius 260 with 5,000 health, which heals 50 a second, about what one heavy tank does to it. It is tier 2. The dome is a sphere around the generator's base. An enemy shell that enters it from outside stops there and does all its damage to the dome, so nothing under it is hit, and a blast does not go off beneath. A shell that starts inside flies out freely, so units under a dome fire out, and units under an enemy dome can still fire at what is there with them. A team's own shells always pass its domes. A splash shell that strikes a dome does its damage to every other enemy dome within its blast radius of where it struck, so overlapping domes all take it (§8.1). Overcharge does at most its structure damage to a dome. A dome that runs out collapses and comes back at full strength after 30 seconds. It costs 30 energy a second while up, less a quarter at most from touching power generators, as factories get. Upkeep is paid first, in `SimId` order, and a dome the team cannot pay for collapses, so an energy stall brings shields down one by one. Pausing a generator (O) drops its dome and its upkeep, keeping its health, and resuming raises it at once. A generator under construction has no dome. The command panel shows a selected generator's shield strength, or how long until it is back. Domes are drawn see-through in the team's color, brighter at the rim and fainter as they weaken. The AI does not build shields yet.
* **Wreck Blasting:** Debris has half the health of the unit it came from, scaled by how much of it had been built: 100 for a light bot, 450 for a heavy tank. A shell that comes down on bare ground hits any debris it lands on, and a blast hits all debris within its radius, including a destroyed unit's death explosion. Debris loses mass and energy in the same proportion as health, and is gone with what is left when its health runs out, so nobody gets that mass. Shells do not hit debris on the way, only where they come down, so debris never shields units behind it. Trees and rocks are not harmed, so the map's starting reclaim cannot be shot away. Attack ground (I, then a click) makes armed units, structures included, fire at a spot until they are given another order, walking until it is in range. It works out of sight, the spot stays in the unit's plan under fog of war, and it takes over the gun, so the unit fires at nothing else. Clicking debris aims at its middle. The shell aims a sixteenth of a unit below the ground: rounding could otherwise leave it just above the ground at the spot, to skim on, and any deeper makes a flat shot land short. The AI does not use it yet.
* **Trees and Rocks:** The skirmish map has 10 forests of 30 trees and 8 fields of 5 rocks on each half, each with its mirror image on the other, clear of the bases, the deposits, and the walls. A tree holds 20 energy and 1 mass, and a rock 5 mass for each unit of its radius, which is 5 to 10, so 25 to 50. Reclaim takes mass at 2 and energy at 10 a second for each unit of build power, both at once, so an engineer clears a tree in under half a second and a large rock in 5 seconds. They do not block movement or building: a structure placed over them clears them, and its team gets what they held, as though its builder had reclaimed them first. Debris under a new structure stays, so that a cheap building on a graveyard cannot take its mass at once. Trees and rocks are part of the map, so they show through fog of war, for the AI as for the player, and its idle engineers reclaim them on their own side. Shooting does not destroy them (see Wreck Blasting).
* **Formation Moves:** Ctrl+right-click, or J and a click, gives a formation move, and Alt makes it an attack-move. A plain right-click stays a plain move. A leader point walks the group's route at nine tenths of the slowest member's speed, so that it can catch up after a bend, and each member keeps to its own spot in a grid that moves with the leader. The grid is the one the group ends in, and turns towards where the leader is heading, no faster than half the pace at its outer spots. The leader waits for members still finishing earlier orders, so a queued formation move sets off together, and for up to 10 seconds for members more than four spacings out of place. On an attack-move it waits while any member is fighting, so the group stops together. A member whose spot is blocked, or more than twelve spacings away, follows the route on its own until it is back in range, and near the goal members leave for their own spots, as in any group order. A formation ends when fewer than two members are left on it. The AI's attack waves do not use formations: at the slowest unit's pace they arrived late enough that, in 200 AI-vs-AI matches, 6 ran past the time limit, against none with each unit at its own speed.
* **Blocked Shots:** A unit does not fire at a target it picked for itself if the ground would stop the shell, which it checks by flying the shell's arc against the terrain. It passes over that target for 5 seconds, so it looks for another or walks on, and an attack-move routes around the hill or wall. A target the player ordered is fired at regardless.
* **AI Waves:** A wave grows by a quarter each time, up to 50 units, but an army that has not grown for a minute goes with what it has, at least 10 units, since a stalled economy may never field the next wave. With nothing in sight, a full-size wave attacks the enemy's base, and smaller waves mostly raid deposits more than 2,000 units from it, away from its defenses. Between equal AIs on a fair map, a defended base beats an equal wave, so without raids to open up a lead, some matches went on past 67 minutes. Gathering each wave short of the enemy's base before attacking was tried and made this worse. After 35 minutes, the commander goes with each full-size wave, which either breaks the enemy's base or loses the commander, and ends the match either way. Waves are never sent at what is under the water, where tanks cannot hit it, and the commander goes only with a wave headed for land: two commanders that followed their waves onto a seabed once stalked each other there, neither able to fire, until the match ran out of time. Once trees and rocks had raised both incomes, an even game could otherwise go on past the limit, with neither commander ever coming under fire.
* **Factory Exits:** A finished unit comes out of the factory side that faces its rally point, or the map center if there is no rally. When two sides face it equally, the one clockwise of it wins.
* **Aircraft:** FAF's UEF T1 numbers, at our scale. An aircraft flies at its own height over land and water, straight for where it is going, with no pathfinding, and bumps into nothing. In flight it never stops: it flies the way it faces and turns at its turn rate, so it moves in arcs. As in the original, an aircraft with nothing to do lands: it flies straight on as it slows and comes down, over 3 seconds, and rests on the ground until it gets an order or a target, when it takes off again just as gradually. Where there is no open ground below, over water, cliffs, or buildings, or near the map's edge, it circles at its height instead, turning in towards the middle near the edge. A landed aircraft is a ground unit: ground weapons and blasts hit it, anti-air does not, and shots already on their way to it are spent. It bombs only from its flying height. A point inside the circles it would turn in cannot be turned to, so it flies on until it can. A move ends within three ticks' flight of the goal, and a group of aircraft keeps no formation. Attacking, it makes passes: having flown over its target, it flies on for its break-off distance before turning back. Only anti-air weapons hit aircraft in flight, and only they can be told to attack one: shots at aircraft steer themselves to them and hit only them, and are spent if the aircraft dies first. Shells and blasts on the ground do not touch aircraft. Aircraft only fight what comes within their weapons' range, and cannot be captured in flight. The Air Factory (T1, 210 mass, 2,400 energy, 4,000 health, 3 by 3, build power 20) builds the Air Scout (40 mass, 580 energy, 35 health, speed 38, height 320, vision 840, radar 1,280), the Interceptor (50 mass, 2,250 energy, 295 health, speed 30, height 280, 50 damage a second within 500, at aircraft only), and the Attack Bomber (90 mass, 2,050 energy, 215 health, speed 20, height 280). The bomber drops one bomb every 5 seconds on ground targets within 800, as it passes over: let go short of the target, the bomb keeps the bomber's speed and falls at the original's gravity, ten times what shells use here, and does 350 within 60, the original's carpet of four napalm bombs and their burning added up. The Anti-Air Turret (T1, 150 mass, 1,500 energy, 800 health, 1 by 1) does 46 every 0.7 seconds within 880, and the Mobile Anti-Air (55 mass, 275 energy, 310 health, from land factories) 26 a second within 640: each volley of two shots in the original is one shot here. The AI builds no aircraft yet.
* **Fuel and Air Staging:** Each aircraft has FAF's seconds of fuel (scout 500, interceptor 300, bomber 400), and burns a tick's worth each tick in the air. With none left it flies at half its height and half its speed. On the ground it refuels at the original's recharge rate of 5, five ticks of fuel each tick. The Air Staging Facility (T2, 175 mass, 2,100 energy, 500 health, 3 by 3) has four pads: a T1 aircraft takes one, a T2 one two, and a T3 one all four. Right-clicking one with aircraft selected sends them to it. Each lands on the first pad free, or circles overhead while they are all taken, and on the pad refuels at 50 times the ground rate and is repaired 500 health a second for 30 energy a second, as FAF's numbers read. Once full on both, it leaves the pad, flies clear of the facility, and lands beside it, as an aircraft with nothing to do over any structure flies on to open ground. A new order ends the trip. As §13.2 asks, aircraft on patrol never land, and below a fifth of a tank go to the nearest of their team's facilities, and back to their patrol once refuelled. A facility destroyed or captured leaves its aircraft where they are.
* **T2 and T3 Aircraft:** FAF's UEF numbers, at our scale. The Air Factory upgrades in its queue to T2 (920 mass, 18,000 energy, build power 40), which adds the Gunship, and to T3 (4,090 mass, 99,400 energy, build power 120), which adds the Spy Plane, Air Superiority Fighter, Strategic Bomber, and Heavy Gunship. A gunship hovers: attacking, it stops in the air within three quarters of its range and turns on the spot to face its target, firing down on it, instead of making passes. The Gunship (192 mass, 3,840 energy, 700 health) fires 16 every 0.3 seconds within 440, and the Heavy Gunship (1,500 mass, 65,000 energy, 6,000 health) 100 every 0.4 seconds within 500. The Spy Plane (195 mass, 7,500 energy, 1,150 health, speed 54) sees 1,280 around it, with radar to 1,920 and omni to 560. The Air Superiority Fighter (450 mass, 51,200 energy, 2,300 health, speed 44) does 500 a second within 600, at aircraft only: the original's two beams of 250 are one shot. The Strategic Bomber (1,750 mass, 180,000 energy, 4,000 health) drops a small nuclear bomb every 8 seconds, 3,100 within 110. Flak bursts on the aircraft it hits and does its damage to every enemy aircraft within its blast: the Flak Cannon (T2, 400 mass, 4,000 energy, 2,590 health) does 125 within 70 every 0.8 seconds, out to 1,000, and Mobile Flak (T2, from T2 and T3 land factories) 72 within 80 every half second, out to 800, the original's two shells as one. The SAM Launcher (T3, 800 mass, 8,000 energy, 5,000 health) fires a volley of 1,200 every 3.6 seconds out to 1,200, the original's six missiles of 200 as one. Flak shells fly at 90, faster than the original's, because shots at aircraft steer to them here rather than being led, and slower ones could never catch the fastest aircraft. The AI builds none of them.
* **Adjacency:** FAF's `AdjacencyBuffs.lua`, unchanged. Each finished structure of the team touching another gives it a bonus that depends on the giver and on the receiver's size class: SIZE4 for 1 by 1 structures, SIZE8 for 2 by 2, SIZE12 for 3 by 3, SIZE16 for factories, and SIZE20 for the largest, with FAF's classes where a footprint here differs (the shield and stealth field generators are SIZE12, the T3 power generator SIZE16, and the quantum gateway SIZE20). Generators take a share off the energy that a factory or an upgrading structure spends, and off upkeep: a T1 generator 1.563% off a factory, 6.25% off a 1 by 1 structure's upkeep and 2.08% off a 3 by 3 one's, a T2 generator or hydrocarbon plant 12.5% off anything, and a T3 one 15.62% off a factory and 18.75% off upkeep. Extractors take a share off the mass that a factory or upgrading structure spends: 7.5%, 10%, or 12.5% off a factory, by tier. Fabricators do a little of the same. Mass storage adds 12.5% to an extractor's output, and energy storage 25% to a T1 generator's, 8.33% to a T2 generator's or hydrocarbon plant's, and 6.25% to a T3 one's. Each neighbor counts once, bonuses add up, and nothing caps them but how many neighbors fit, except that no discount reaches 90%. The Energy Storage (T1, 250 mass, 1,200 energy, 500 health, 1 by 1) holds 10,000 energy, and is on `[`.
* **Artillery:** FAF's UEF numbers, at our scale. Artillery cannot hit what is closer than its least range, and its shells land at a random spot within its spread of where they are aimed, drawn from the simulation's own random numbers, so that every replay scatters them the same way. The Artillery Installation (T2, 1,900 mass, 13,585 energy, 3,600 health, 1 by 1) fires 2,000 within 60 every 20 seconds, from 1,000 out to 2,300, with a spread of 50. The Heavy Artillery Installation (T3, 76,000 mass, 1,424,000 energy, 15,000 health, 5 by 5) fires 7,840 within 120 every 13.3 seconds, from 3,000 out to 16,500, with a spread of 9.3. Their turrets turn slowly, at 6 and 3 degrees a second. An installation's shot costs energy, 1,000 or 16,000, taken all at once as it fires, and it waits until the team has it: FAF charges it over the reload instead. Generators beside an installation cut that cost and the time between shots, by FAF's adjacency table: a T2 generator 5% and 6.25% off a 1 by 1 installation. Mobile Heavy Artillery (T3, from T3 land factories, 800 mass, 8,000 energy, 950 health) fires 750 within 80 every 10 seconds, from 500 out to 1,800, with a spread of 25. The installations are on `]`. The T1 Light Artillery keeps its own numbers for now, and the AI builds none of these.
* **Extra Weapons:** A unit may carry weapons beyond its main one, in `extra_weapons`, each firing shells, or shots that steer to aircraft. Each picks its own target: the one its unit was ordered to attack, if it can hit it, or else the nearest enemy it can hit, mobile units first, on the same cadence as main weapons. Each reloads on its own and turns its own turret, and those that hit the ground fire at a ground attack's spot. A unit can be ordered to attack anything any of its weapons can hit. The strategic bomber and heavy gunship carry their anti-air guns this way, and the Fighter-Bomber (T2, FAF's Janus: 360 mass, 12,600 energy, 1,200 health, from T2 and T3 air factories) a carpet of napalm, twenty bombs of 80 as one of 1,600, and railguns that do 150 a second to aircraft within 600.
* **Ships:** Ships sail water deep enough for them, where each corner of a cell is at least 10 below the water, and float on it. They have their own pathfinding over the water, worked out the same way as on land, made the first time a ship needs it, so that games without ships are unchanged. A group of ships and land units given one order gets a route for each, and a ship sent to land goes to the nearest water. Structures on the water block ships, and structures that go on water, such as the naval factory, need deep water under all of them, and launch their ships onto it. FAF's UEF numbers: the Naval Factory (T1, 300 mass, 1,500 energy, 4,500 health, 3 by 3, build power 20, on `\`) builds the Frigate (280 mass, 2,800 energy, 2,120 health, speed 12, radar 1,600), with a gun of 85 every 1.7 seconds out to 560, and a railgun of 5 a second at aircraft out to 960. Engineers build a naval factory from the shore, within their build range. It upgrades to T2 (2,000 mass, 10,000 energy, build power 90) and T3 (9,500 mass, 45,000 energy, build power 150) headquarters, and T2 and T3 builders build FAF's naval support factories (1,100 and 2,200 mass) under the same rules as land and air ones. The Destroyer (T2, 2,250 mass, 7,200 health) has two gauss cannons of 305 every 4 seconds out to 1,200 and a railgun at aircraft. The Cruiser (T2, 2,000 mass, 2,500 health, radar 3,040) fires its cruise missiles on its own, 300 within 40 every 2.5 seconds out to 3,000, which launchers it picks targets for and needs no missiles built for, and has a gauss cannon, SAMs that do 1,000 every 2 seconds to aircraft out to 1,400, and a Phalanx that shoots down tactical missiles within 1,200. The Battleship (T3, 10,000 mass, 51,000 health) has three gauss turrets of 3,000 every 20 seconds out to 3,000, the original's three shells each as one, railguns at aircraft, and a Phalanx. The Battlecruiser (T3, 7,000 mass, 25,000 health) is faster, with two plasma cannons of 210 every 6.7 seconds out to 1,600, and a Phalanx. The destroyer and battlecruiser also carry torpedoes.
* **Under the Sea:** A submarine sails just under the water, on the same water as ships. Submerged, it is on a layer of its own: only torpedoes reach it, and shells and blasts pass over it. It is hidden from the enemy, sight and radar alike, unless the enemy's sonar covers it: then it is a contact on the map, and in sight, it is in full view and can be shot at, as with radar. Torpedoes steer to their target, ships and submarines only, as shots at aircraft do, and are spent if it dies or is gone. FAF's UEF numbers: the Attack Submarine (T1, from naval factories, 360 mass, 800 health, sonar 1,200) fires 150 every 4 seconds out to 640; the Torpedo Bomber (T2, from T2 and T3 air factories, 270 mass, 860 health, sonar 880) drops fifteen torpedoes of 150 a run, as one; the Sonar (T1, 150 mass, sonar 3,200, 20 energy a second) upgrades to T2 (300 mass, sonar 5,760, 100 energy a second); and the Torpedo Launchers (T1, 450 mass, 360 every 4 seconds out to 1,000; T2, 1,080 mass, 720 out to 1,200) go on water. Every ship has FAF's sonar too. Torpedoes run at 30, faster than the original's launch speed, because they steer here rather than speed up, and slower ones could never catch a ship. The sonar and torpedo launchers are on `-` and `=`, which set the volume when nothing selected builds them.
* **Amphibious:** Hovercraft and seabed walkers cross land and water alike, by a third pathfinding of their own over land land units can cross and any water, made the first time one needs it. A hovercraft floats on the water and is hit there as on land, by anything but torpedoes. A seabed walker walks along the bottom: while all of it is under the water it is submerged, as a submarine is, so that only torpedoes reach it and only sonar finds it, and it can fire nothing but torpedoes. As in the original, the commander and support commanders walk the seabed. A group of land units, amphibians, and ships given one order gets a route for each. FAF's Amphibious Tank (T2, the Riptide, from T2 and T3 land factories, 320 mass, 1,800 health, speed 7.4) hovers, with a riot gun of 13.5 every 0.3 seconds out to 360. Engineers of every tier hover, as the original's UEF engineer does: they travel on land and float on the water, where they can build naval structures far from the shore. On a map without water this changes nothing: with the unit data's own hash left out and a hovercraft's movement hashed as a land unit's, an AI match's checksum matched the land engineers' on every tick to its end.
* **Shields That Move:** A shield may be carried by a unit, and its dome goes with it, on the water for a ship. FAF's Shield Boat (T2, from naval factories, 900 mass, 550 health) has a dome of 5,500 health that covers 660 around it on the water, the original's sphere of 1,200 sunk 1,000 under the surface, for 100 energy a second.
* **Anti-Torpedo Charges:** A unit's charges shoot down the nearest enemy torpedo within their range each time they reload, as a tactical missile defense does missiles. The destroyer and battlecruiser have FAF's Smart Charge, one torpedo within 600 every 10 seconds. So that a charge stops part of a torpedo bomber's run and not all of it, the bomber drops five torpedoes of 450 every 2 seconds, the original's fifteen of 150 a run.
* **Missiles From Units:** Launchers that store missiles, the tactical and strategic missile launchers and the strategic missile submarine, build one only when told to, or one after another: right-clicking a missile's build button turns that on, marks it "(auto)", and right-clicking again turns it off, as the factory repeat does. They fire what they store only on order. Automatic launchers pick their own targets and need nothing built, and an extra weapon may be one. Both fire from under the water. FAF's Strategic Missile Submarine (T3, from T3 naval factories, 9,500 mass, 4,000 health) builds and stores up to three nuclear missiles, fired on order out to 8,200, and fires cruise missiles of 2,000 within 60 every 10 seconds on its own, out to 5,120. FAF's Mobile Missile Launcher (T2, from T2 and T3 land factories, 180 mass, 825 health) fires a cruise missile of 300 every 5 seconds on its own, the original's two a volley as one, out to 1,300, and cannot hit what is closer than 240. The amphibious tank moved to the fifth slot of a land factory's bar, on C, as the mobile missile launcher took the artillery slot.
* **Exotic Weaponry:** A weapon's data may give it a stun in seconds. What its shot hits, or its blast reaches, is stunned that long: it cannot move or fire, any of its weapons, its radar, sonar, and omni are off, its cloak, stealth, and jamming stop, and its shield dome is down, so shells pass where it stood. A stun on a stunned unit only ever lengthens it. As in FAF, aircraft are never stunned. A stunned unit, either side's, is marked "STUNNED" while it is in sight. A tractor beam is a weapon kind: it takes hold of one enemy that moves on land at a time, never a commander, an experimental, or a structure, holds it in the air, helpless as if stunned, and draws it in, so that it reaches the holder as its crush time runs out and is destroyed, with the credit to the holder. If the holder dies first, the unit is let go and falls back to the ground. The beam is drawn while it holds. A unit's data may give it a death storm, which it leaves where it is destroyed: the storm drifts toward the nearest enemy within eight times its radius, looking again every second, wanders a random way with none in sight, strikes each enemy under it every tick, never its own side, and blows out when its time is up. It is drawn as a flickering disk.
* **Pause:** The player can stop the game clock with the Pause button beside the match clock, or Ctrl (or Cmd) + P, and start it again the same way. While paused no tick runs, so the AI is paused too, and "PAUSED" shows across the top. The camera, selection, and orders all still work: orders given meanwhile are carried out in order on the first tick after resuming, as if given then. The pause lives in the driver, outside the simulation, so it changes nothing that is replayed or checked. With one human player it is theirs alone; with lockstep multiplayer (§17) it will have to be a command every peer applies on the same tick.
* **AI Tech and Economy:** The AI climbs the land tech tree. Its first land factory upgrades to T2 at 8 mass a second and to T3 at 30, and its other T1 factories to T2 at 20, one upgrade at a time, and only while nothing stalls and its energy income is at least ten times its mass income, since an upgrade draws a great deal of energy. Once it has a headquarters, new factories are support factories of that tier. A factory first makes engineers of its own tier, up to 2 plus one for every 5 mass a second and no more than 10, and keeps 3 T2 and 2 T3 engineers once it can build them. Its other units follow its tier: at T1, light bots with every fourth a light artillery; at T2, heavy tanks, with light bots, amphibious tanks, and mobile missile launchers mixed in; at T3, the same with mobile heavy artillery. Generators come before extractors while its energy lags its mass, and are the only thing it builds while its energy runs out, since extractors cost upkeep. It builds T2 generators from 15 mass a second and T3 ones from 45, with the engineers that can, while smaller builders help. Idle builders help finish any structure of 500 mass or more, then an extractor upgrading, then a factory. From 10 mass a second, extractors upgrade nearest home first, one at a time plus one for every 25 mass a second, to T2, and from 40 also to T3, unless energy is short or the team is stalling. Extractors pay their upkeep before anything is built, so a team whose generators are all destroyed, and whose income is less than its extractors cost, can never finish another generator: on Twin Passes, raids did that to both sides in one match, which then sat unchanged for 45 minutes. When its energy is gone and its income no more than its running extractors' upkeep, the AI pauses its extractors and moves every builder working on anything else onto generators, and starts the extractors again once energy is half full. Until then it builds only T1 generators, one at a time, with the other builders assisting it: a trickle of energy split between several T2 sites, at 12,000 energy each, finished none of them. Without this, an AI that lost every generator at 15 minutes had none and no energy 10 minutes later; with it, it rebuilt them. Two changes keep both sides of a mirrored match the same: putting generators first keeps the opening energy stall short, where before, with energy empty for minutes, a builder arriving one tick sooner finished its generator 40 ticks sooner, and upgrades wait for an economy that can feed them. With nobody playing Red, the AI has T3 factories and engineers, at least six upgraded extractors, higher-tier generators, and over 60 mass a second by 25 minutes. Shields, intel, and missiles are not yet in its play.
* **AI Air:** The AI builds an air factory once it has a T2 land headquarters or 15 mass a second, needing no mass in store for the first, and a second at 50. Air factories upgrade to T2 at 25 mass a second and to T3 at 60, while its energy income is at least twenty times its mass income, and once it has an air factory it builds generators to that ratio rather than twelve, since aircraft cost far more energy than land units. While energy is under half full, air factories start nothing. A third of what they make are fighters, the interceptor or at T3 the air superiority fighter, and the rest strike aircraft: the bomber at T1, the gunship and every fourth a fighter-bomber at T2, and the heavy gunship at T3. Against enemy aircraft, two thirds are fighters. Idle fighters patrol between home and the rally point, where they stay in the air and engage whatever comes. Strike aircraft gather at home and set out once there are 6, then 2 more each time up to 16: at the visible enemy nearest home, structures first, or else an outlying deposit or the base, as the land waves choose, and then fly home. With 6 aircraft it builds an air staging facility. Once it has seen an enemy aircraft, and for 5 minutes after, every fourth land unit is mobile anti-air or, at T2 and above, mobile flak, and its builders put up anti-air toward the enemy, the best each can build: 2, plus one for every 20 mass a second, up to 6. The land army ignores enemy aircraft, which it cannot hit.
* **AI Navy:** On a map with water, the AI works out once where its naval factories can go: deep water within 7,000 of its start, nearer its start than the enemy's, nearest first, with ties going by the cell as seen from Blue's side so that a mirrored map gets mirrored choices. On Twin Passes the sea's deep water is 5,855 from each start. It also finds the deep water nearest the enemy's start, where its fleets go. It builds a naval factory once it has a T2 land headquarters or 20 mass a second, needing no mass in store for the first, and a second at 60, each with a cell of open water around it, out on the water where its engineers float. Naval factories upgrade to T2 at 30 mass a second once it has 3 ships, and to T3 at 70 once it has 6, so that a factory does not spend its first minutes only upgrading. They build frigates and attack submarines at T1; destroyers, frigates, cruisers, and a shield boat at T2; and battleships, battlecruisers, destroyers, cruisers, and a shield boat at T3, and send new ships to wait off the first naval site. Ships and submarines are the fleet's, apart from the land army. Idle ships meet any enemy on or under the water within 7,000 of home, and otherwise set out together once there are 4, then 2 more each time up to 12, for the water nearest the enemy's start, shelling what they find. On a map without water, it plans and builds nothing for the sea.
* **AI Defenses and Intel:** Once the base has two factories, the AI builds a radar toward the enemy, and upgrades it to T2 at 40 mass a second. With a radar, a blip on the ground within 1,400 of its start draws its idle army, as a seen enemy does; blips more than 30 above the ground or water are aircraft and are left alone. With T2 builders, and energy keeping up with its income, it builds shield generators near home from 20 mass a second (one more for every 30, up to 4), tactical missile defenses toward the enemy from 20 (one more for every 40, up to 3), and one tactical missile launcher from 25. Planned sites keep their whole footprint clear, not just a corner, which on Red's plan, turned about the map, was the opposite corner and moved its larger buildings two cells off Blue's mirror image. The launcher builds missiles one after another, and fires at enemy structures in sight and in range, extractors first, then the nearest. The commander overcharges the costliest enemy unit already in its gun's range, when it has the 3,000 energy with 1,000 to spare and is above half health, but never the enemy commander, nor anything within 900 of it. A commander's reactor takes the other with it when they die close together, and one shot kills a commander: overcharging anything in reach drew 7 of 200 soak matches.
* **Upgrade Indicator:** Anything upgrading has the same pulsing ring around it: a commander or support commander being fitted with an enhancement, a factory on an upgrade at the front of its queue that is not paused, and a structure upgrading in place. An enemy's shows too, but only while the unit is in sight, never on a radar blip, and with nothing more: not what it is becoming, nor how far along it is. The viewer's own upgrades also show a progress bar under the health bar.
* **Build Menus:** Every build menu, a builder's or a factory's, is one bar. It starts with a T1, T2, T3 toggle, and shows only the items of the level chosen, each with just its key and name. Levels with nothing to build are greyed out. The level chosen is remembered, one for builders and one for factories, and a menu with nothing of that level shows its lowest. Hovering over an item shows its cost and build time, health, and what it does: its weapon, speed, income, upkeep, storage, shield, and sensors, and for factories, how many of those selected can build it. Hotkeys work at any level. A factory's upgrade, repeat, and clear buttons sit on the row below.
* **A Fair Skirmish Map:** The skirmish map turns into itself about its center, and the AI plays it that way. It lays out its base from Blue's side, then turns each site for Red, footprint included. Both commanders start at the center of a terrain cell, never on a cell edge, because a point on an edge belongs to the cell above and to the right of it, so its mirror image would be in the wrong cell. Both AIs think on the same tick, since a side that always thought later would always be that far behind, and they draw the same random numbers. Until the armies meet, Red plays Blue's game turned around. What is left is noise: fixed-point rounding is not symmetric under negation, and paths of equal cost can bend differently on each side.

## 19. Data & Simulation Requirements

* **Unit Data:** Unit and structure stats live in versioned data files, not code, using fixed-point-safe values and loaded identically on every instance. Each entry defines at least cost (Mass, Energy, Build Time), health, speed, footprint, movement class, build options, weapons, intel ranges, and resource rates.
* **Economy Precision:** Economy totals, storage, and veterancy XP use 64-bit fixed-point, because their values can exceed the range of the engine's `Fp` type. When demand exceeds supply, resources are shared among consumers using integer math in a fixed order, so stalling stays deterministic.
* **Large Footprints:** Pathfinding for wide units needs cost grids inflated by unit size, in addition to one grid per movement class. Experimentals cannot be added without this.
* **Open Numbers:** Values this document leaves undefined must be set in the data files before their feature is built. Examples include the exact energy-stall build rate, the veterancy regeneration curve, and all T1–T4 unit stats.

## 20. Naming & Licensing

Faction, unit, and structure names in §2 and §14 are working references taken from *Supreme Commander: Forged Alliance*. They must be replaced with original names, and designs reviewed for similarity, before any public release. Code and data files use neutral identifiers (for example `faction_a`, `t2_heavy_tank`) so that renaming does not touch game logic.

This is a non-commercial, open-source game, inspired by *Forged Alliance* but its own game. The rules, kept in [PROVENANCE.md](PROVENANCE.md):

* **No borrowed code.** Everything is written for this project. A formula taken from elsewhere is credited where it is used and in PROVENANCE.md.
